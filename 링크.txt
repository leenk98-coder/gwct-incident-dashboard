- AskHost 컴포넌트 + ask() 신설 (Promise 반환). App 트리 맨 뒤에 항상 렌더.
  브라우저 기본 대화상자를 쓰지 않으므로 어느 환경에서도 동작함.
    const ok  = await ask({ title, message, danger:true });            → true / null
    const why = await ask({ ..., input:{ label, fallback:"경미건" } });  → 문자열 / null
- 교체한 4곳
    1) 영구 삭제        window.confirm → 앱 모달(빨간 경고)
    2) 사고 취소        window.prompt  → 앱 모달 + 취소 사유 입력칸(기본 '경미건')
    3) 첨부 삭제        window.confirm → 앱 모달
    4) JSON 가져오기 덮어쓰기
       건마다 confirm 을 N번 띄우던 것을 → 한 번만 묻고 [덮어쓰기]/[건너뛰기] 선택
       건너뛴 건수를 완료 메시지에 표시
- 삭제·취소 실패 시 flash() 로 오류를 띄움(이전에는 조용히 실패)
- window.confirm / prompt / alert 사용처: 0곳 (전량 제거됨)
